Claude AI Skills Pack: Pharma Marketers Edition
================================================
11 ready-to-install AI skills for pharmaceutical and consumer healthcare marketing.
Built for Claude Code.

HOW TO INSTALL
--------------
1. Copy each folder from the /skills directory into:
   ~/.claude/skills/

   Mac/Linux terminal:
   cp -r skills/marketing-plan ~/.claude/skills/
   cp -r skills/campaign-planner ~/.claude/skills/
   (repeat for all 11 folders)

2. Open a new Claude Code session.

3. Type the skill command to activate:
   /marketing-plan
   Claude detects and loads it automatically.
